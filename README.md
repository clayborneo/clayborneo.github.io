# rainbowagama.com

Landing page for Clay Thomas's sites and workspaces. Static HTML, no build step.
Served by GitHub Pages from this user-site repo (`clayborneo.github.io`) with the custom domain
`rainbowagama.com`; every other public project site of the account answers at
`rainbowagama.com/<repo>/`. `agamaagama.com` redirects here at the Cloudflare edge.

Art: the desert, sky and creatures come from the Cool Baby site (Clay's own work).
